# FilmFoundry Skills v2.1 全方面评分

评审日期：2026-09-07  
评审对象：`codex/filmfoundry-v2-release`，并结合《雾城夜巡档案》项目适配器的实际接入状态。  
评分尺度：10 分制。分数表示“当前仓库能稳定支持的程度”，不是对最终视频质量的预测。

## 总评

**综合：7.7/10（适合进入小规模、证据驱动的生产试运行；还不适合宣称覆盖从生成到发布的完整自动化生产）。**

这个分数不是把 8 个技巧简单相加。FilmFoundry 已经把大多数高风险决策变成了可记录、可检查的契约，但图片/视频/音频实际执行和审美判断仍在外部工具或人工手中。对小白团队而言，地基明显比“堆一条万能提示词”可靠；代价是前期登记、状态和回填工作较多。

## 对博客八项方法的判断

| 方法 | Skill 支持 | 当前判断 |
|---|---|---|
| 面部近景 + 正/背全身 + 可选去头全身 | **已表达、可校验** | 适合高复用角色；去头策略仍是 `UNVERIFIED`，不应默认强制 |
| 湿身/受伤/带血/换装变体与局部蒙版 | **部分支持** | 状态变体、父资产、mask 区域可登记；PS/局部回贴执行和效果仍外部/人工 |
| 固定声音描述、样本、测试台词、漂移记录 | **已表达** | Voice Passport 能记录，但语音生成和口音稳定性未实证 |
| 3/4 场景与锚点物 | **已表达、可校验** | Location Reference + Spatial Map；3/4 的普遍收益仍未证实 |
| 空间地图 | **较强支持** | 主体、锚点、关系、距离、相机侧、屏幕方向、光源可记录 |
| 1 秒全景预演 | **已表达** | Previs 可作为输入；不会自动等于最终镜头，收益需实验 |
| 大小参照 | **较强支持** | Scale Reference 要求可见参照关系，避免只写“30 米” |
| FOV/镜头结果 | **已表达** | 要求数字与可观察画面结果并存；不会假设模型真正理解焦段 |
| 物理运动描述 | **已表达、人工复核** | 力、重量、惯性、重力、材料响应和 observable result 可登记 |

## 目前不能宣称的能力

- 不能宣称 FilmFoundry 自己生成图片、视频、声音或完成剪辑发布。
- 不能宣称灰色背景、去头全身图、3/4 场景、预演或 FOV 数字对所有模型有效。
- 不能宣称 Prompt 通过就等于身份一致、空间稳定、物理真实或审美合格。
- 不能把 H3 Smoke 或单次 `OBSERVED_ONCE` 结果升级为默认路线。
- 不能把静态 Keyframe/QC 通过当作成片或 Picture Lock。

## 最需要改进的地方

1. **真实证据闭环**：完成 `TEST_H3_06_A` 外部回传，再做灰背景、去头、3/4、预演和镜头描述的单变量 A/B。
2. **新手向导**：把“今天只做一个镜头”的最小路径做成可复制示例，减少第一次接触时的文档跳转。
3. **适配器执行层**：在项目适配器中补充真实 Provider 回传导入、媒体规格审计和 Select/QC 回填，但保持核心不绑定平台。
4. **发布闭环**：增加音频、字幕、交付编码和发布证据的项目级样例；这些应继续标为外部工具或人工审核。

## 结论

这套 Skill 值得继续使用和迭代。它最强的价值是把“经验技巧”转成可追溯的视觉事实和证据等级，而不是承诺某种神奇提示词。对当前小团队，建议用小规模垂直切片验证，不要先建设完整模型矩阵或批量生成。
