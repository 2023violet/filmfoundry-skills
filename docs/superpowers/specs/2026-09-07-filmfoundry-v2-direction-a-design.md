# FilmFoundry Skills v2.0 Direction A Design

FilmFoundry is a provider-neutral contract and evidence layer. Higgsfield,
MiniMax H3, Wucheng paths, credentials, generation APIs, media downloads,
audio, NLE, encoding, and publishing are adapters or external operations.

## Authorities

Markdown is human authoring authority; JSON and CSV are machine state
authority; media bytes are entities whose measured dimensions, mode, alpha,
and SHA-256 are recorded by the registry. Relative paths resolve from the
manifest root. `99_归档` is read-only and inventory-only.

## Evidence rules

Structural contract errors block. Creative guidance is a warning. `OBSERVED_ONCE`
cannot establish default provider behavior or unlock a production route. Real
provider output must include raw media, settings evidence, generation ID,
hash, and human QC before promotion.

## Provider boundary

The core accepts a canonical prompt and capability snapshot and returns a
deterministic compiled payload. Adapters interpret provider-specific roles and
parameters. The first Higgsfield adapter imports capability snapshots and
performs dry-run compilation only. H3 remains a project smoke adapter.

## Identity references

`NEUTRAL_IDENTITY_REFERENCE` is guidance for clean neutral-gray identity
references. Its effect on identity stability is unverified until a controlled
single-variable experiment records comparable outputs.
