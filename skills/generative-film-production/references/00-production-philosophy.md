# Production Philosophy

AI filmmaking is a controlled production system, not prompt roulette. Separate decisions by lifetime: creative intent belongs in the brief, persistent identity in asset passports, shot decisions in canonical specs, provider quirks in adapters, and verified lessons in model profiles.

Favor observable, reviewable states over adjectives. “Oppressive” is useful only after it becomes visible cues; “consistent” is useful only after the invariant is named. Design the smallest generative unit that can succeed independently and keep downstream work replaceable.

A production artifact earns promotion by passing a gate. Expensive generation never substitutes for missing design work, and post-production owns tasks that deterministic tools can execute more reliably.
