# Creative Brief

Capture only decisions that change the production: audience, format/platform, duration range, purpose, Point X (what the viewer should understand/feel/do), core message/story, emotional arc, delivery specs, and hard constraints.

## Gate

Mark `BRIEF_LOCKED` when the audience, outcome, format, and non-negotiable constraints are explicit enough that two producers would not plan different projects from the same brief.

Use `../templates/creative-brief.md`.
