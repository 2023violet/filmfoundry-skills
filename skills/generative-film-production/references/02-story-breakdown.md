# Story Breakdown

Convert prose into sequence → scene → shot candidates before writing prompts. For each shot record narrative goal, one dominant action, duration range, characters/assets, location, props, dialogue verbatim, and edit intent.

Split a shot when it asks one generation to solve several independently failing actions, incompatible camera instructions, or a location/time discontinuity. Merge shots only when the action is genuinely continuous and the model route can support the duration.
