# Asset Passport

Create one authoritative passport for every recurring character, product, prop, vehicle, creature, or location. Store 3–5 visible invariants, canonical descriptor, approved references, and allowed state variants.

State changes are explicit variants such as `CHAR_A_DRY` → `CHAR_A_WET`; do not silently mutate canon. A new reference can be proposed, tested, then promoted. It never silently replaces the authority record.

Use `../templates/asset-passport.md` and the asset registry validator.
