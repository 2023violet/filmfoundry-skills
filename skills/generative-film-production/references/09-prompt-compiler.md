# Prompt Compiler

Compile the Canonical Shot Spec; do not reinvent it. Remove facts already carried robustly by the route, retain expensive locks, translate craft terms into observable descriptions when recognition may vary, and append only model-profile biases that are actually measured.

Typical I2V compilation prioritizes reference binding, motion, camera, stages, acting, physics, audio, end state, and expensive locks. Typical T2V additionally needs subject, environment, composition, and lighting because no start image supplies them.

Keep canonical data unchanged when switching models; only the adapter output changes.
