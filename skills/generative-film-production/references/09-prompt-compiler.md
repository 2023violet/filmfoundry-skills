# Prompt Compiler

Compile the Canonical Shot Spec; do not reinvent it. Remove facts already carried robustly by the route, retain expensive locks, translate craft terms into observable descriptions when recognition may vary, and append only model-profile biases backed by evidence.

Typical I2V compilation prioritizes the primary visual frame, the smallest necessary identity/prop references, one camera logic, motion, a small number of stages/end states, acting, physics/persistence, audio ownership, and failure conditions. Typical T2V additionally needs subject, environment, composition, and lighting because no start image supplies them.

Reference-role language is an adapter strategy, not a universal fact. If a Model Profile has not shown repeatable semantic role-binding behavior, use a minimal reference pack or a precomposed keyframe rather than writing increasingly elaborate `controls X only` prose and assuming compliance.

Before emitting a provider prompt, run an integration pass: compare the prompt's
initial state, shot size, camera, blocking, and lighting against the approved Shot
Spec. Flag state drift when the prompt makes a person visible, changes the action
moment, or turns an observational frame into a portrait without an explicit human
decision. For subject-in-location shots, keep common-light, scale, occlusion,
contact, and focus requirements observable rather than relying on the phrase
"photorealistic" or "well integrated".

The relative best candidate from a batch is not automatically an approved result;
the prompt compiler and keyframe QC use the same quality bar, and all candidates may
be rejected.

A compiled prompt is one executable provider plan. Do not include alternative six-second and ten-second timelines in the same prompt. Resolve the actual generation duration first. Separately keep the edit target in the shot/runtime contract; the prompt does not need to demand that every source second become a Select.

Do not add dense second-by-second timing to ordinary motion merely to appear precise. Exact timing belongs to a named external authority or to deterministic post. Load `23-controllability-budget.md` when provider obedience is being replaced by prompt length.

Keep canonical data unchanged when switching models; only the adapter output changes.
