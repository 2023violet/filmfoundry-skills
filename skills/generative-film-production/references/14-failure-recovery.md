# Failure Recovery

Diagnose before retrying. First ask whether the source contains a valid contiguous `PARTIAL_SELECT`. If the selected range alone fulfills narrative purpose, quality bar, and downstream continuity, use it and stop paying to perfect unused seconds.

If a retry is necessary, convert the failed observation into the smallest causal hypothesis and change one related variable.

Examples: disappearing prop → make ownership/state persistent in stage end states or split the hand/prop action; identity swap → reduce competing references or move identity locking into a validated keyframe; over-cutting → remove timestamp density/conflicting camera commands; weak reverse angle → rebuild from axis/eyeline instead of tail-frame chaining; character looking away from the narrative target → repair the keyframe/eyeline contract upstream rather than asking video to rescue it; unstable dialogue → separate performance video from an approved voice-timing route; camera over-push or acting amplification → shorten the edit target or simplify the camera/acting burden when model evidence supports that adaptation.

Use controlled attempts 1–3 for diagnosis. By attempts 4–5, simplify the shot, reference pack, camera path, or dialogue burden. A sixth repeated failure blocks the current route: split the generation unit or change model/adapter strategy. Do not hide structural failure behind endless sampling or giant rewritten prompts.
