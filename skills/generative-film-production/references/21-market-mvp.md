# Market MVP

The MVP exists to learn whether people want the content **before** FilmFoundry pays the full production tax.

## MVP rules

1. Test the content engine, not your maximum render quality.
2. Keep only the production elements needed to make the hypothesis understandable.
3. Avoid large canon packs, exhaustive world bibles, voice libraries, and complex continuity unless the hypothesis specifically depends on them.
4. Predeclare the audience, hook, payoff, follow reason, platform hypothesis, and success criteria.
5. Create a small controlled set of variants rather than one expensive “perfect” pilot.
6. Record production time and direct generation cost as part of the result; a concept that performs but is uneconomic needs a cheaper route before scale.
7. Change one content variable per comparative variant when practical: hook, premise framing, episode structure, or payoff—not every element simultaneously.

## AI-video MVP heuristic for short-form narrative

This is a **low-cost starting heuristic**, not a universal format law:

- roughly 30–60 seconds per episode;
- roughly 5–8 edit units;
- roughly 3–6 seconds of useful footage per edit unit;
- one main character when identity matters;
- one or two locations;
- voice-over or off-screen narration when it reduces fragile lip-sync burden;
- one dominant visual action per generated clip;
- a visible hook early and an episode-end reason to continue.

If the concept only works with ten speaking characters, choreography, long lip sync, precise hand-prop interaction, and many locations, either simplify the MVP or accept that it is a high-cost hypothesis.

## Evidence review

After publication, compare real results with the declared criteria. Record what the evidence supports and what it does not support. A result may validate the hook but not the thirty-episode engine; validate the audience but not the cost; validate views but not follow intent.

Only promote to `PRODUCTION_APPROVED` when the market-gate evidence contract passes. Otherwise run the next cheapest experiment or stop.
