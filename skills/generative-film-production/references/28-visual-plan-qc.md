# 28 · Visual Plan QC

## Narrative
- one primary visual fact per anchor;
- information release is readable without explanation;
- the anchor advances the intended beat.

## Continuity
- recurring identity is correct;
- location anchors persist where required;
- state/prop/light/weather are intentional;
- axis and eyeline are correct when applicable.

## Provider fit
- no visual plan assumes a capability not verified on the selected provider route;
- first/last frames are used only for state transitions that actually need them;
- multi-reference boards are not treated as semantic role contracts unless evidence supports that behavior.

## Edit fit
- a planning frame can be held, cropped, pushed, cut away from, or omitted;
- it is not required to become a one-to-one final shot.
