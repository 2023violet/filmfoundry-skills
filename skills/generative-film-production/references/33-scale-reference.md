# 33 - Scale Reference

## Purpose

Use visible scale evidence when the audience must read the size relationship
between a subject and a known object, person, opening, or architectural unit.
A numeric label by itself is not visible evidence.

Each scale relation names:

- the `subject_id`;
- the `reference_object_id`;
- the visible relation that lets a reviewer judge size;
- the intended scale statement;
- a confidence value that describes the authored plan, not provider obedience.

Examples include a child beside a standard doorway, a giant crossing a street
with parked vehicles, or a handheld prop compared with the character's hand.
Choose a reference that remains visible in the intended composition.

## Workflow

1. Choose the smallest reference object that makes the relationship readable.
2. State what should be visible: relative height, reach, clearance, overlap, or
   travel distance.
3. Bind the reference object to the Asset Registry and the shot composition.
4. Check the intended crop and perspective before generation.
5. Review the selected result for the visible relationship and record the
   result separately from the plan.

Do not hide a scale change in vague words such as "epic" or "huge." Do not use
unmeasured camera language as a substitute for a visible relationship. The
scale contract can guide a provider, but it cannot establish a default
capability without dated evidence.

Use the scale entries in `templates/visual-control-plan.example.json`.
