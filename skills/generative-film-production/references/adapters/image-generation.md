# Image Generation Adapter

Use image generation for master assets, state variants, style anchors, and shot keyframes. Bind each source to the smallest authority it should provide and preserve approved identity/state rather than redesigning recurring assets for each shot.

For video keyframes, load `../17-keyframe-engineering.md`. Compile one still action moment from the resolved shot spec. Let style, canonical/state-variant characters, location/spatial references, and critical props own their specific visual domains. A keyframe prompt must not contain a multi-stage video timeline.

Approve the keyframe on identity/count/state/prop/location/axis/composition/anatomy before I2V. Video generation does not repair an invalid start frame.
