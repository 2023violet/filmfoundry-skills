# Content Market Gate

Use this before expensive Production for audience-growth, monetization, or repeatable-series work.

| Gate | Answer |
|---|---|
| One-sentence conflict | |
| Who watches? | |
| Why click? | |
| First 3-second hook | |
| What does the viewer get? | |
| Why follow the next episode? | |
| Can the narrative engine sustain 30 episodes? | |
| What can eventually monetize? | |
| What is the cheapest MVP? | |
| Why is this format a fit for current AI-video capability? | |
| Which platform/audience hypothesis is being tested first? | |

## Decision

Choose exactly one: `NO_GO`, `TRAFFIC_EXPERIMENT`, `MVP_ONLY`, `PRODUCTION_APPROVED`, `BYPASS`.

`PRODUCTION_APPROVED` requires dated real MVP evidence against criteria declared before publishing. If monetization has no answer, stay a `TRAFFIC_EXPERIMENT` rather than pretending the content has a commercial route.
